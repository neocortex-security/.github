# neocortex-security

Tooling for Prisma Cloud → Cortex Cloud migrations and Cortex Cloud deployments,
built on real engagements and validated against live tenants.

| Tool | One line |
|---|---|
| [rql2xql](https://github.com/neocortex-security/cortex-security-automation/tree/main/rql2xql-preview) | RQL → XQL translation, validated by population against live tenants |
| [cspm-rules-manager](https://github.com/neocortex-security/cortex-security-automation/tree/main/cspm-rules-manager-preview) | Prisma policies, Cortex rules, standards, AppSec rules and exceptions from reviewed workbooks |
| [cspm-rules](https://github.com/neocortex-security/cortex-security-automation/tree/main/cspm-rules-preview) | Consolidated, validated Cortex Cloud rule library |
| [cortex-cloud-terraform](https://github.com/neocortex-security/cortex-security-automation/tree/main/cortex-cloud-terraform-preview) | Provisions the managed security service framework for a Cortex Cloud tenant, as code |
| [prisma_asset_reporter](https://github.com/neocortex-security/cortex-security-automation/tree/main/prisma-asset-reporter-preview) | Per-asset findings and vulnerabilities from Prisma Cloud, cross-cloud, at scale |
| [cortexcloud-sentinel](https://github.com/neocortex-security/cortex-security-automation/tree/main/cortexcloud-sentinel-preview) | Cortex Cloud in Microsoft Sentinel, and in OpenSearch + Grafana on AWS |

Public previews live in **[cortex-security-automation](https://github.com/neocortex-security/cortex-security-automation)**;
source and binaries are in private repositories — see
[ACCESS](https://github.com/neocortex-security/cortex-security-automation/blob/main/ACCESS.md).
